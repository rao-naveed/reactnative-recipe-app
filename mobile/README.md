# 🍳 Full Stack Recipe App 📱

Yeh ek full-stack Recipe Application hai jiske backend Node.js/Express par aur mobile frontend React Native/Expo par bana hai. Ismein Stripe Payment Gateway integrarted hai premium access ke liye.

## ✨ Features

- **Recipes:** Recipes ko browse, search, aur category-wise filter karein.
- **Auth:** Clerk Auth ya standard signup/login system integration.
- **Payments:** Stripe integrations ke saath Unlimited Recipes tak access.
- **UI/UX:** React Native ke saath clean design.

---

## 🛠️ Tech Stack

- **Frontend:** React Native, Expo, React Navigation, WebView.
- **Backend:** Node.js, Express, Stripe, PostgreSQL (Drizzle ORM).
- **Database:** Hosted on Neon/Supabase/ElephantSQL.

## ⚙️ Setup Instructions

### Backend Setup (`/backend`)

1. Go to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file based on `.env.example` and add your keys.
4. Start the server:
   ```bash
   npm run dev
   ```

### Mobile Setup (`/mobile`)

1. Go to the mobile directory:
   ```bash
   cd mobile
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file with your `EXPO_PUBLIC_API_URL`.
4. Start the app:
   ```bash
   npx expo start
   ```
